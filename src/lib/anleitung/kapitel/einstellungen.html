Das Dokument «Einstellungen» enthält Daten, die für die ganze Website gelten:

  • Tab «Main»: Website-Titel und -Untertitel, verantwortliche Person bzw. Firma, Adresse, E-Mail-Adressen, Kontakte fürs Impressum und die rechtlichen Texte (Datenschutzerklärung, Haftungsausschluss, Impressum, Cookies-Text, AGB). Ausserdem Seiten-Passwort, Chat-Bot, Mehrsprachigkeit und Startseiten-Umleitung.
  • Tab «SEO»: globale SEO-Angaben, Favicon, App-Icon und Statusleisten-Farbe.
  • Je nach Paket weitere Tabs: «Rechnungen» (Grundwährung, IBAN, Bank, BIC / SWIFT, Zahlungsfrist, MWST-Satz, «QR-Zahlteil auf Rechnungen»), «Terminbuchung», «Online-Handel», «Ressourcenbuchung».
  • «Absender-E-Mail (alle E-Mails der Website)» im Tab «Main»: Von dieser Adresse kommen alle E-Mails der Website (Buchungen, Rechnungen, Newsletter, Formulare). Die Domain muss beim Mail-Dienst (Resend) eingerichtet sein – das erledigt Angelo. Ist das Feld leer, werden keine E-Mails versendet; «Inhalte prüfen» im Admin-Bereich zeigt das an.
  • «Absender-Name» (Tab «Main»): Name, unter dem die E-Mails erscheinen, z. B. der Name deines Geschäfts. Leer = Website-Name.
  • «Benachrichtigungen an (intern)» (Tab «Main»): An diese Adresse gehen interne Meldungen wie neue Buchungen, Formular-Nachrichten und Bestellungen. Leer = «Verantwortliche E-Mail».

«Startseite umleiten» mit «Umleitungs-Seite»: Besucher der Startseite werden automatisch auf eine andere Seite weitergeleitet, z. B. während einer Umbauphase. Bleibt «Umleitungs-Seite» leer, erscheint die Standardseite «Website im Aufbau» mit deiner «Verantwortlichen E-Mail» als Kontakt; sie zeigt nur die rechtlichen Links, keine Navigation.
