• Prismic ist das CMS (Backend), in dem du deine Website pflegst. Anmeldung unter prismic.io mit deinem Benutzerkonto.
  • Inhalts-Typen (in Prismic «Type»): das Grundgerüst, z. B. Page (Seite), Navigation, Einstellungen, Design-Vorlage, Event. Mehrfache Typen (z. B. Page, Event) kannst du beliebig oft anlegen. Einmalige Typen (z. B. Navigation, Einstellungen) gibt es nur einmal; ist er schon angelegt, erscheint er in der Auswahlliste blass.
  • Inhalts-Elemente (in Prismic «Slice»): Bausteine, aus denen eine Seite zusammengesetzt wird, z. B. Titelbereich, Text, Bild, Akkordeon, Kacheln, Formulare. Viele Inhalts-Elemente haben Varianten (Variations), z. B. Text «Standard», «Zwei Spalten» oder «Überschrift».
  • Dokument: ein einzelner Eintrag, z. B. die Seite «Über mich».
  • Veröffentlichen (Publish): Erst veröffentlichte Änderungen sind auf der Website sichtbar. Gespeichert wird automatisch.
