Alle Felder, die einen Ort auf der Karte festlegen, heissen Kartenpunkt:

  • im Element «Karte einbetten»
  • im Element «Adresse und Karte»
  • im Element «Event»
  • im Inhalts-Typ «Event» (Tab «Ort»)
  • im Inhalts-Typ «Ort / Standort»

Die Karte wird immer mit OpenStreetMap angezeigt, egal welchen Link du einträgst. Besucher laden dabei nichts von Google.

Das kannst du ins Feld «Kartenpunkt» eintragen

  • Am einfachsten: auf openstreetmap.org den Ort suchen, «Teilen» wählen und den Kurzlink (beginnt mit https://osm.org/go/) oder die «Geo-URI» (beginnt mit geo:) kopieren.
  • Koordinaten: Breite, Länge, z. B. 47.3769, 8.5417.
  • Google Maps: der Link aus «Teilen» → «Link kopieren» (https://maps.app.goo.gl/…) oder der Code aus «Karte einbetten» (<iframe …>). Beim Einbettungscode zählt die Kartenmitte; hast du den Ausschnitt verschoben, sitzt der Punkt leicht daneben.
  • Apple Karten oder map.geo.admin.ch (swisstopo): den Link zum Ort.
  • Leer: keine Karte.

Achtung: Ein Google-Link auf einen Ort ohne Koordinaten (z. B. https://www.google.com/maps/place/Name) wird nicht erkannt. Im Admin-Bereich unter «Inhalte prüfen» erscheint er als «Kartenpunkt nicht erkannt».
