1. Neues Dokument anlegen

Klicke auf der Prismic-Startseite oben rechts auf Create a new page.

2. Typ wählen

Wähle in der Liste Page.

3. Seitentitel eingeben

  • : kurz und möglichst genau, das ist wichtig für Suchmaschinen

4. UID eingeben

  • : Teil der Adresse im Browser
  • Kleinbuchstaben, keine Umlaute, Bindestriche statt Leerzeichen
  • Auf der ganzen Website einmalig

Beispiel: Aus «Über mich» wird «ueber-mich», die Adresse lautet dann deine-website.ch/ueber-mich.

5. Inhalts-Elemente hinzufügen

Füge mit dem Plus-Symbol Inhalts-Elemente hinzu und befülle sie.

Verwende pro Seite nur eine Überschrift der höchsten Ebene (H1).

6. SEO ausfüllen

Fülle im Tab SEO & Metadata Meta-Titel, Meta-Beschreibung und Vorschaubild aus.

7. Veröffentlichen

Veröffentliche die Seite.

8. In der Navigation verlinken

Verlinke die Seite in der Navigation (siehe nächste Anleitung).

Solange sie nicht verlinkt ist, finden Besucher sie nicht. Du erreichst sie aber direkt über die Adresse mit der UID.
