3. Ergebnis

Besucher sehen nun zuerst eine Passwort-Abfrage. Nach der Eingabe bleibt die Freigabe eine Weile im Browser gespeichert.

Wichtig

Der Passwortschutz ist eine praktische Hürde, aber kein sicherer Tresor.

  • Technisch versierte Personen können die Inhalte und teilweise das Passwort über das Hintergrundsystem einsehen.
  • Keine vertraulichen Daten (Kundendaten, Verträge, Zugangsdaten, interne Kalkulationen) auf geschützte Seiten stellen.
  • Kein Passwort verwenden, das du anderswo nutzt.
  • Für einen wirklich geschlossenen Bereich (Kundenportal, Mitarbeiter-Login) bitte Angelo kontaktieren.
