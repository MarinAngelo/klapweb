Für lange Seiten wie Anleitungen oder häufige Fragen gibt es zwei Arten von Suche (ab Paket Professionell):

  • Suche auf der ganzen Seite: Element «Schaltfläche» in der Variante «Suche» einfügen. Die Schaltfläche öffnet ein Suchfenster, das den Inhalt dieser Seite durchsucht, auch zugeklappte Akkordeon-Einträge. Ein Klick auf einen Treffer öffnet den Eintrag und springt an die Stelle.
  • Suche in einem Akkordeon: Im Element «Akkordeon» «Suche aktivieren» einschalten und optional den «Suchfeld-Platzhalter» anpassen. Über dem Akkordeon erscheint ein Suchfeld, das nur dessen Einträge filtert.

Durchsucht wird immer nur die Seite, auf der die Suche steht, nicht die ganze Website.
