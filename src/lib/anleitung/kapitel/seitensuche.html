Für lange Seiten wie Anleitungen oder häufige Fragen gibt es zwei Arten von Suche (ab Paket Professionell).

Suche auf der ganzen Seite

Füge das Element Schaltfläche in der Variante Suche ein.

Die Schaltfläche öffnet ein Suchfenster, das den Inhalt dieser Seite durchsucht, auch zugeklappte Akkordeon-Einträge.

Ein Klick auf einen Treffer öffnet den Eintrag und springt an die Stelle.

Suche in einem Akkordeon

Im Element Akkordeon:

  • einschalten
  • optional anpassen

Über dem Akkordeon erscheint ein Suchfeld, das nur dessen Einträge filtert.

Achtung: Durchsucht wird immer nur die Seite, auf der die Suche steht, nicht die ganze Website.
